# JiMo Shorts Uploader · 工具说明（一页纸）

> 给平台审核方 / 合作方看的说明。口语化，不堆术语。

## 这是什么
一个跑在我（创作者）自己 Mac 上的小工具。功能就一件事：**把我亲手做的竖版短视频，通过各平台官方 API，发到我自己的 Facebook / Instagram / TikTok / Pinterest 账号。**

## 谁来操作
只有我一个人。它不是给别人用的 SaaS，也不是代发平台。账号、视频、发布，全是我的。

## 怎么用（典型一天）
1. 我本地产出一批竖版短视频（1080×1920，25–30 秒，多语言 Shorts）。
2. 工具做本地预处理：统一下变换分辨率、生成封面、封装优化（让各平台能稳定接收）。
3. 我**逐条人工确认**要发哪条、发到哪个平台、配什么标题。
4. 工具按我设定的时间窗（Facebook 用平台原生定时，其余本地错峰）把视频发到我自己的账号。
5. 本地写一份发布日志（去重、重试、出错自动熔断），留痕可追溯。

## 隐私声明（一句话版）
- 视频只在**我自己电脑**上处理，不上任何云。
- 只读你账号的公开信息，用来确认“发到我自己账号”。
- 不碰观众数据、不卖数据、不接第三方。
- 授权令牌只存我自己 Mac 的钥匙串，随时能撤销。

## 为什么这样设计
本地处理 + 官方 API + 人工确认，三件事合起来就是：安全、可控、可追溯。任何一步都能停、能撤销、能查。
