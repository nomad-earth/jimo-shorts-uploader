JiMo Shorts Uploader

个人创作者的自有短视频自动分发工具 · 仅用于把自己的视频发布到自己的账号

本地运行自用逐条人工确认

这是一个运行在创作者本人电脑上的工具，用于把自己制作的原创短视频，通过各平台官方 API，分发到自己自己的 Facebook、Instagram、TikTok、Pinterest 账号。每一条发布前都需创作者本人确认，不批量搬运、不代发第三方内容。

它做什么 / What it does

  • 读取本地已制作好的短视频（竖版 1080×1920），经本地预处理（下变换、生成封面、封装优化）后，通过平台官方 API 发布。
  • Facebook 支持服务端原生定时；其余平台由本地调度器在设定时间窗内错峰发布。
  • 全程本地处理，不把视频上传到任何第三方云，也不采集任何观众数据。
  • 每条发布前由创作者人工确认；本地记录发布日志（去重、重试、异常熔断）。

技术说明 / Technical notes

  • 仅使用各平台官方开发者 API，授权范围最小化（只申请发布所必需的 scope）。
  • OAuth 令牌仅保存在创作者本机（macOS Keychain），不上传、不共享。
  • 所有发布行为可逆、可控：令牌可随时撤销，创作者可随时停止工具。
